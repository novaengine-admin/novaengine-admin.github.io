## Notes

Region names in your data must match the names below **exactly**, including capitalisation and any suffix.
{: .warning }

- Where an LGA name is shared with another state, the name carries a suffix: `Bayside (NSW)`, `Campbelltown (NSW)`, `Central Coast (NSW)`. Use the full name including the suffix.
- The map also contains non-geographic entries (`Migratory - Offshore - Shipping (NSW)`, `No usual address (NSW)`, `Unincorporated NSW`). Ignore them unless your data uses them.
