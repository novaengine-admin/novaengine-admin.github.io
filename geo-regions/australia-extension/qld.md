## Notes

Region names in your data must match the names below **exactly**, including capitalisation and any suffix.
{: .warning }

- Where an LGA name is shared with another state, the name carries a suffix: `Central Highlands (Qld)`, `Flinders (Qld)`. Use the full name including the suffix.
- The map also contains non-geographic entries (`Migratory - Offshore - Shipping (Qld)`, `No usual address (Qld)`). Ignore them unless your data uses them.
