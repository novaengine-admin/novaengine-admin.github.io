## Notes

Region names in your data must match the names below **exactly**, including capitalisation and any suffix.
{: .warning }

- Where an LGA name is shared with another state, the name carries a suffix: `Bayside (Vic.)`, `Kingston (Vic.)`, `Latrobe (Vic.)`. Use the full name including the suffix.
- The map also contains non-geographic entries (`Migratory - Offshore - Shipping (Vic.)`, `No usual address (Vic.)`, `Unincorporated Vic`). Ignore them unless your data uses them.
