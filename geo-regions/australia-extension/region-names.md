# Region Names

The value in your data's name field must match a region name below **exactly**, including capitalisation and any suffix such as `(Vic.)`.
{: .warning }

Every map matches on the boundary file's `LGA_NAME25` property. Each map also contains a few non-geographic entries (for example `No usual address`) that you can ignore unless your data uses them.
