## Notes

Region names in your data must match the names below **exactly**, including capitalisation and any suffix.
{: .warning }

- Where an LGA name is shared with another state, the name carries a suffix: `Central Coast (Tas.)`, `Central Highlands (Tas.)`, `Flinders (Tas.)`, `Latrobe (Tas.)`. Use the full name including the suffix.
- The map also contains non-geographic entries (`Migratory - Offshore - Shipping (Tas.)`, `No usual address (Tas.)`). Ignore them unless your data uses them.
